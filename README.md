# Q SHIFT（キューシフト）

**答えの先まで、面白い。**

時間制限も対戦もない、ひとり用のブラウザークイズ。スマホでもパソコンでも、自分のペースで遊べます。歴史、地理、鉄道、美術、建物の設計、街の歴史、外国語の単語など、気になるジャンルからどうぞ。

## 遊び方

- ジャンルと出題数を選び、「クイズを始める」を押します。
- 選択肢から答えを選んで「答えを確認する」を押すと、正解・解説・根拠資料が表示されます。
- 資料は別タブで開きます。読み終えたら元のクイズのタブに戻ってください。
- 間違えた問題は、あとから解き直せます。

## 読みやすさと途中再開

「表示設定」で文字を大きくしたり、高コントラストに切り替えたりできます。対応するブラウザーでは、問題・選択肢や正解・解説を読み上げられます。

表示設定・復習履歴・進行は、保存が有効なブラウザー内に残ります。途中から再開するときは、同じブラウザーで同じページを開いてください。
